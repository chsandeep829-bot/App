# RapidBet Live (Regenerated Demo)

This is a complete static demo app with:
- Gmail login + OTP simulation
- Wallet with UPI deposit and withdraw flows
- Strict deposit proof verification: UTR + screenshot filename + payment datetime token
- Deposit credit after 10 seconds (post verification)
- Withdraw transfer simulation after 1 minute
- AI-refreshed live cricket matches + odds + fancy + scorecard
- Aviator game card, VIP profile, and transaction statement

## Run locally

```bash
python3 -m http.server 4173
```

Open: `http://localhost:4173`
